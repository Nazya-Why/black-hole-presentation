# Горизонт подій — презентація

Статичний сайт-презентація: на фоні — чорна діра, що рахується в реальному часі (WebGL),
поверх — Liquid Glass і типографіка в стилі Apple, 15 слайдів-заготовок.
Без збірки й залежностей — можна одразу викладати на GitHub Pages.

## Запуск локально

```bash
python -m http.server 5173
```

Відкрити http://localhost:5173

## Керування

- колесо / тачпад, стрілки, Space, PageUp/PageDown, Home/End
- свайп на телефоні
- точки праворуч, кнопки внизу
- `F` — повний екран
- `#7` в адресі — одразу відкрити 7-й слайд
- `?fps` в адресі — лічильник кадрів

## Фон

`js/background.js` — промінь з камери летить крізь викривлений простір навколо діри,
тому задня частина диска видна над і під тінню, а навколо — тонке фотонне кільце.

- диск обертається за Кеплером (внутрішні кільця швидші), бік, що летить до нас, яскравіший (Допплер)
- темна планета на нахиленій орбіті, освітлена диском
- кожен слайд має свій ракурс (`data-cam` у `index.html`), камера перелітає між ними;
  під час перельоту диск коротко прискорюється, а лінзування на мить ширшає
- легкий паралакс від курсора

Ракурс слайда: `data-cam="відстань висота нахил x y яскравість"` — опис у коментарі в `index.html`.

Сцена рахується в зниженій роздільності (~0,5 Мпікс) і сама дешевшає, якщо кадри не встигають.
На вбудованій Intel UHD — 60–70 к/с без зниження якості.

## Структура

- `index.html` — слайди (`<section class="slide">`), атрибути описані в коментарі над ними
- `css/style.css` — токени, скло, переходи, макети
- `js/background.js` — чорна діра, великі слова на фоні, зерно
- `js/glass.js` — рефракція Liquid Glass (Chromium; в Safari/Firefox — матове скло)
- `js/deck.js` — навігація
